Only what this person may do

The selection bar shows the actions this person may take on this list. A row they may not act on is skipped, with why.

Row by row

The server does each row on its own, in its own transaction, with the same core call as a single row. Up to 500 rows.

One reason for all

A void or delete asks one reason for every row. The audit trail holds one event per row.

The result stays

Done, unchanged, skipped with why, not found. It stays on screen, with each skipped row and a link to retry.

New endpoints: POST /api/books/core/<document>/bulk/<action>, one per action, built like the CRM’s record bulk and retail’s requisition bulk routes.
