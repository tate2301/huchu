Vane wrote this questionYou asked for won m² beside measured. It joins Site visit forms to Deals, so it is written in SQL; Steps cannot join.
select date_trunc('month', f.visited) as month,
       sum(f.area_measured_m2) as won_m2
from crm_visit_forms f
join crm_deals d on d.deal_no = f.deal
where d.outcome = 'Won'
  and f.visited between period_start() and period_end()
group by 1 order by 1
7 rows in 0.04 s, read only. Won m² is 1,957.4 in all, the same as the figure above.
