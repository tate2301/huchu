Open quotes since September

StepsChange either side; the other follows
  1. Start from site_visits since 1 September
  2. Bring in the customer, the fitter and the quote
  3. Keep visits with no quote, or a quote not accepted
  4. Sort by quote total, biggest first
SQL, read only:since = 2026-09-01
select v.visited_on, c.name as customer, s.name as fitter, v.area_m2, q.total, coalesce(q.state, 'no quote') as state, current_date - v.visited_on as days_sincefrom site_visits vjoin customers c on c.id = v.customer_idjoin staff s on s.id = v.fitter_idleft join quotes q on q.site_visit_id = v.idwhere v.visited_on >= :since and (q.state is null or q.state <> 'accepted')order by q.total desc nulls last;
