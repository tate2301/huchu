Vane

Why Vane feels part of the workspace

Eight rules every screen that shows Vane follows. Breaking one is a defect, the same as a wrong font.

The rules

Checked in review with the lint and by eye.

01
It has no window of its own

No chat app, no floating bubble. Vane appears in the top bar, the panel, beside records and in drafts.

02
It uses the workspace’s components

Its cards, plans, flags and drafts are built from the same kit as every module: the same buttons, tables, shortcuts and focus ring.

03
It takes the workspace’s theme

Tender’s orange in a retail workspace, Campus’s in a school. Only the mark stays ink, so Vane is recognisable everywhere.

04
It speaks like a colleague

First person, plain, with names and exact amounts. It ends with “Let’s …”. The button says the act: Send 3 reminders, never Do it.

05
It shows its working

Every item can show the records it read and the SQL it ran. Nothing it says is unchecked.

06
It waits for a person

Sending, paying, approving and changing are always a person’s press, enforced on the server.

07
It respects people’s time

Quiet hours hold messages. Muted items stop coming back. One morning message, not a stream.

08
It is never called AI

The interface says Vane. Claude is named once, on the Vane page in Management, as what Vane runs on.

Keys

Every primary action has one.

Ctrl JOpen or close the Vane panel
SSend, on the focused card
RCheck the run, on a pay run card
TabTake a suggested answer
EscClose the panel
