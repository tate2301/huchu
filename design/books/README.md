# Corelith Books, handover for Claude Code

1. Copy this folder into the Corelith app repository as `design/books/`.
2. Optional: save the owner's "Books, final form" spec as `design/books/spec/books-final-form.md`. Where it differs from this folder on scope, it wins.
3. Open Claude Code in the repository and say: "Read design/books/CLAUDE.md and start phase 1. Propose the data model and migration first."

Phases: P1 core, engine and rights · P2 the $10 screens · P3 Bank & cash and Books inside CRM, Retail, Payroll and Reports · P4 Accounting advanced ($99) · P5 mass actions, outside accountants and export.
