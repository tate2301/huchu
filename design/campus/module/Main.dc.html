The caption line is not deleted — it is repointed

It stops explaining the title and starts carrying the state that changes. This is the teacher portal's rule, lifted verbatim.

Caption instead — carries the state

Where nothing changes, there is no caption. A page whose only context is its own name gets a title and nothing else — that is most of them.
This is already shipped code, not a proposal. teacher-portal-shell.tsx dropped its category line for exactly this reason — “it repeated what the rail already says” — and spends its caption on the term and the class in view. page-intro.tsx already discards its purpose and nextStep props. The admin modules are what has not caught up.
