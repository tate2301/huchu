What ships instead

The report card’s subject table is a single row reading “Results data will be populated from the results module for the selected term.” The marks above are what the screen is for and what it does not yet fetch. The fee invoice prints Tuition Fee, Boarding Fee and Total Due, each with a literal “-”.

The two tabs with no filter

Class Lists and Attendance Registers reuse the student search state but never render the search box, so they print all 842 pupils with no way to narrow to a class. The filter row above is the fix, and it is the same FilterBar every other campus screen already uses.
