The rows start from the roll

A targets list built from the targets table can only show the children somebody has already thought about. The head’s question is the other one — which pupils have no target at all — so a pupil with nothing set is a row saying so.

No mark is not behind

A missing mark says nothing about how the target is going, so it is neutral rather than a warning. Reading it as “behind” would put a child on a chase list over a test nobody has marked.

The missing half

The screen’s whole purpose is naming the 238 pupils nobody has set a target for — and today there is no way to set one from here. Every row is a dead end. Set a target on the row, and one over the filtered set, is what turns the list into work.
