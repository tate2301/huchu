# R-4.3 — the four detail routes

Taken by driving the real app against the `acme` demo tenant, to prove each
route renders against real rows before the work landed. **Not regenerated by a
committed spec:** the ids are this database's and mean nothing anywhere else, so
the spec that took them was throwaway.

`e2e/retail-shots.spec.ts` photographs the list screens on static paths and can
keep doing so. Photographing a detail route needs an id, and hard-coding one
into the maintained suite would make it fail the first time somebody re-seeds.

| Shot | Route | What it shows |
|---|---|---|
| `sale.png` | `/retail/sales/{id}` | RSL-0006 — two Castle at $1.20, $10 cash, $7.60 change, and the refund RSL-0007 against it |
| `shift.png` | `/retail/shifts/{id}` | RSH-0008 — float, takings, the $20 drop to safe, and the transactions behind it |
| `order.png` | `/retail/purchasing/orders/{id}` | PO-0001 — ordered against received, per line, with $119 still to come |
| `catalog-item.png` | `/retail/catalog/{id}` | Johnnie Walker Black — the shelf price and **which list it resolved off** |
